# Mini-Drone-
It's a mini quadcopter powered by 
- Xiao ESP32 S3 (FC)
- MPU 6050
- 8520 Coreless Motor 2xCW & 2xCCW
- 55mm Propeller 2xCW & 2xCCW
- Coustom motor drive:
    • SI2300 1N-MOSFET 4x
    • 1N4148 Diode 4x
    • 10k ohm Resistor 4X

- CRSF reciver ( I have an ER8G )
- A transmitter supporting you Reciver ( I have an Radio Master Pocket)
